## Replication

```bash
P=scripts/analysis/stage1_crosswalk_sdot_274/pilot.py; OUT=analysis_out/stage1_crosswalk_sdot_274
python $P sample --inventory <crosswalk-inventory-274>/analysis_out/crosswalk_inventory_274 --out $OUT
python $P meta --inventory <same> --census <Phase 0 census OUT> --out $OUT   # network: GSV search
python $P fetch --out $OUT                                                   # network: GSV pixels
python $P place --out $OUT                                                   # GPU: Vistas
python $P report --out $OUT && python $P figures --out $OUT && python $P gallery --out $OUT
```

`search_cache.jsonl` is the network record (re-running `meta` reuses it; delete it to re-search). GSV coverage changes, so a fresh search moves the yield numbers.
