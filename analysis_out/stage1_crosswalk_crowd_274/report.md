## Replication

```bash
C=scripts/analysis/stage1_crosswalk_sdot_274/crowd_arm.py; OUT=analysis_out/stage1_crosswalk_crowd_274
INV=<crosswalk-inventory-274>/analysis_out/crosswalk_inventory_274; CEN=<Phase 0 census OUT>
PANOS=<copy of makelab2 sidewalk_panos/Panoramas/seattle-wa for the selected ids>
python $C select --inventory $INV --census $CEN --panos $PANOS --out $OUT   # network: streetlevel metadata
python $C place --inventory $INV --census $CEN --panos $PANOS --out $OUT    # GPU: Vistas
python $C export --out $OUT && python $C report --out $OUT && python $C gallery --out $OUT
```

The pano copy: one read-only `tar cf - --verbatim-files-from -T -` stream from makelab2 over `./<id[:2]>/<id>.jpg` paths (ids may start with `-`).

| number | lives in |
|---|---|
| label classes, verdicts, crowd pixels | `selection.csv` |
| pano position, heading, date | `crowd_meta.jsonl` |
| every mark, on-paint, B2 | `placements.csv` (one row per pano × label or SDOT crosswalk) |
| the training set | `crowd_labels.jsonl` (one record per pano) |
